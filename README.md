# Figuras e listagens de *A Metáfora da Bolholândia*

Este repositório reúne, em alta resolução e prontas para download, todas as
figuras e todas as listagens de programa do livro **A Metáfora da Bolholândia**,
de Antonio Ferrão Neto, nas suas duas edições — portuguesa e inglesa.

Cada figura impressa no livro traz um QR code na legenda. O código leva ao
arquivo correspondente aqui.

## Como está organizado

```
pt/figuras/volI/figura37/Vol_I_Figura_37.pdf      ← Volume I, Figura 37 (edição em português)
en/figuras/volI/figura37/Vol_I_Figure_37.pdf      ← o mesmo, edição em inglês
pt/listagens/volIII/listagemAG.1/…                ← programas listados no Volume III
```

`volI`, `volII` e `volIII` são os três volumes da obra. O caminho reproduz
exatamente o endereço impresso no QR code, e o nome do arquivo diz a que volume
e a que figura pertence — para que continue identificável depois de baixado.

## Baixar

- **Tudo de uma vez:** botão verde **Code → Download ZIP**, no alto desta página.
- **Um arquivo:** navegue até ele e use o botão de download.
- **Por linha de comando:** `git clone https://github.com/impnet-br/metafora-bolholandia-figuras.git`
