What this is about

The challenge invites the reader to build a low-cost electronic circuit that solves the equation x² − 2 = 0, extracting the digits of √2 by analog measurement rather than by conventional numerical computation. The goal is not to compete with multiple-precision libraries, but to demonstrate, in physical hardware, that an analog device with only three digits of precision can contribute to a result of arbitrary precision.

The full statement of the challenge — assembly requirements, the refutation criteria declared a priori, and the verifier program — appears in the appendix on the Successive Zooms Method, in volume III of The Bubbleland Metaphor.

How to submit

A submission must contain enough detail for an independent third party to rebuild the setup and obtain equivalent results without consulting the participant. By equivalent we mean this: the digit chain must be identical, since it is mathematical and does not depend on the setup; the measured voltages, the breaking stage and the per-block error rate, however, depend on components, calibration and ambient conditions, and of these we expect only agreement within the declared tolerances.

The material stays hosted in the participant's own public repository. This page publishes only the consolidated index of results, linking to each project.

To submit, write to contato@impnet.com.br with the repository address. The full step-by-step guide — what to log during the run, the control test and what to publish — is on the help page.

The offline verifier — a Python program using only the standard library, with nothing to install — is at verificar.py. It compares the submitted digits against √2 computed by exact integer square root, with no floating point, and reports the breaking stage. Run it on the control log as well.
