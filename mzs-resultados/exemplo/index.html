Submissão de exemplo · Example submission

Desafio MZS · SZM Challenge

Esta submissão é fictícia. Não corresponde a nenhuma montagem real nem a resultado recebido de participante algum. Existe para demonstrar o formato esperado e para que o participante confira a própria montagem contra um caso completo.

This submission is fictitious. It corresponds to no real build and to no result received from any participant. It exists to show the expected format and to let participants check their own build against a complete case.

Os dois registros abaixo são autênticos naquilo que importa para o teste: o log principal passa no verificador, e o log de controle quebra no primeiro estágio — como tem de quebrar quando a leitura analógica é substituída por ruído.

Arquivos

ArquivoConteúdo
log_estagios.csv Sessão de aquisição, 128 estágios (categoria Prata). Colunas: stage, digit, trials, monitor_a/b/c, quantity, temp_c, vref_v.
log_controle.csv Ensaio de controle: a leitura analógica é substituída por valor aleatório, mantendo o resto do firmware.
componentes.csv Fabricante, modelo e lote de cada componente crítico.
firmware.ino Esboço do laço de controle. O valor de √2 não figura em ponto algum do arquivo.
esquematico.svg Diagrama de blocos da montagem.
README.md Descrição do conjunto.

Como conferir

python verificar.py log_estagios.csv    # 128/128 dígitos corretos
python verificar.py log_controle.csv    # quebra no primeiro estágio

O segundo comando é o que importa: se a cadeia sobrevivesse ao ruído, o bloco analógico não estaria contribuindo, e a submissão não demonstraria o método. O verificador está em verificar.py.
